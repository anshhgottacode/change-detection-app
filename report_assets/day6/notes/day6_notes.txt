1. Annotation protocol
----------------------
REPORTED:
- Tool: Photopea. About 5-10 minutes per pair. One annotator (the author), so no agreement measure exists.
- Masks were drawn on the processed (aligned) before image; white (255) = changed, black (0) = unchanged; masks match the processed image size exactly.
- Marked: objects added or removed; for a clearly moved object, the old and new positions.
- Not marked: shadows, lighting differences, reflections, the black border outside the aligned overlap; an object cropped out of the other frame was not marked as removed.
- pair2 (satellite) was too uncertain to mask and is excluded from annotated evaluation. No precision, recall, F1 or IoU is reported for it.

3. Evaluation setup
-------------------
- eval_utils.py: STATIC = {nochange, shiftstatic, lightstatic}; static pairs use an all-zero mask; annotated masks are read from ../ground_truth/<pair>_gt.png (threshold > 127); a size mismatch stops the run; a missing mask skips the pair.
- Evaluation region: the overlap area from detect_changes(method="diff", align=True) if alignment works, else the whole frame. Every variant is scored over the same region.
- Metrics: precision, recall, F1, IoU, TP/FP/FN, predicted changed-pixel % ("pred%").
- Variants, all with default settings (blur 5, Otsu threshold, morphology 5x5, minimum area 200 px, max width 1280): V1 diff; V2 ssim; V3 diff+align; V4 diff+CLAHE; V5 diff+match; V6 diff+align+CLAHE; V7 diff+align+match; V8 ssim+align.
- No parameters were tuned for the main comparison.
- For static pairs, recall is n/a and F1/IoU print as 0.000 by convention; ignore them. Only pred% (the false-change rate) is meaningful.
- The sweep (section 7) varies threshold, minimum area and blur using V3 settings and the same ground truth, so its best values are exploratory, not held-out test scores.

12. Problems found, limitations, anything odd
---------------------------------------------
- Small dataset (four annotated pairs, three assumed-static pairs, one excluded); one annotator; hand-drawn masks.
- Otsu's automatic threshold is far from the best tested threshold on the annotated pairs (section 7) and can pick very low values on near-identical images (nochange aligned, threshold 9).
- Variants behave differently per scene (SSIM best on pair1 but poor under shift; alignment helps shiftobj but not pair1; normalisation after alignment hurt shiftobj).
- Alignment fails on the satellite pair even with looser settings.
- A homography cannot model parallax in a 3D scene (INTERPRETATION for pair3).
- The sweep uses the same ground truth it is evaluated on.
